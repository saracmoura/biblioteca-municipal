```
# 📚 Biblioteca Municipal

> Sistema para gestão, empréstimos e organização do acervo da Biblioteca Municipal.

```

---

## 📖 Sobre o Projeto

O **Biblioteca Municipal** é um projeto desenvolvido para otimizar o gerenciamento de acervos bibliográficos, controle de usuários e registro de empréstimos e devoluções de livros. O objetivo principal é automatizar rotinas administrativas e facilitar o acesso à leitura.

---

## ✨ Funcionalidades

* 📑 **Gestão de Acervo:** Cadastro, edição, remoção e busca detalhada de livros e exemplares.
* 👥 **Controle de Usuários:** Gerenciamento de leitoras(es) cadastrados e histórico de acessos.
* 🔄 **Empréstimos e Devoluções:** Registro ágil de retiradas, prazos de devolução e status do livro.
* 📊 **Relatórios:** Monitoramento de livros mais lidos, prazos vencidos e estatísticas do sistema.
